## 🚀 Como publicar no GitHub Pages

### Passo 1 — Criar repositório
1. Acesse **github.com** e faça login
2. Clique em **"New repository"** (botão verde)
3. Nome do repositório: `financas-facil`
4. Marque como **Public**
5. Clique em **"Create repository"**

---

### Passo 2 — Subir os arquivos
Na página do repositório criado, clique em **"uploading an existing file"**

Arraste todos os arquivos de uma vez:
- `index.html`
- `manifest.json`
- `sw.js`
- `icon.svg`
- `README.md`

Clique em **"Commit changes"** (botão verde)

---

### Passo 3 — Ativar GitHub Pages
1. Clique em **Settings** (aba do repositório)
2. No menu lateral, clique em **Pages**
3. Em **"Branch"**, selecione `main`
4. Clique em **Save**
5. Aguarde ~1 minuto

---

### Passo 4 — Seu link estará disponível em:
```
https://SEU_USUARIO.github.io/financas-facil/
```

> Substitua `SEU_USUARIO` pelo seu nome de usuário do GitHub

## 📱 Como instalar no celular

### Android (Chrome)
1. Abra o link no Chrome
2. Aparece um banner **"Adicionar à tela inicial"** — toque nele
3. Ou: menu ⋮ → **"Adicionar à tela inicial"**
4. Pronto — ícone aparece na tela inicial

### iPhone (Safari)
1. Abra o link no **Safari** (obrigatório)
2. Toque no botão **Compartilhar** (quadrado com seta ↑)
3. Role para baixo e toque em **"Adicionar à Tela de Início"**
4. Toque em **"Adicionar"**
5. Pronto — ícone aparece na tela inicial

## 🔄 Como atualizar o app

Quando houver uma versão nova do `index.html`:
1. Acesse o repositório no GitHub
2. Clique no arquivo `index.html`
3. Clique no lápis ✏️ (editar)
4. Selecione tudo (Ctrl+A) e cole o novo conteúdo
5. Clique em **"Commit changes"**

Todos os usuários receberão a atualização automaticamente na próxima abertura.
